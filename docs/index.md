# DTG Portfolio Monitor

This site provides evidence-backed monitoring and situational awareness across the Decentralized Trust Graph ecosystem.

## Operating proposition

The monitor does not replace GitHub, task-force governance, specifications, or implementation repositories. It preserves observed activity, assigns transparent review signals, maps that activity to a declared DTG capability model, and surfaces cross-workstream implications that deserve attention.

Three views serve different levels of inquiry:

- **DTG Domain Brief** — what the observed portfolio movement means.
- **Dashboard** — where capability movement and convergence are occurring.
- **Portfolio Status** — the detailed event register and source evidence.
