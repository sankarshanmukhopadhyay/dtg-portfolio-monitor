# DTG Portfolio Monitor

This site provides evidence-backed monitoring and decision support across the Decentralized Trust Graph ecosystem.

## Start with decisions, then inspect evidence

The monitor does not replace GitHub, task-force governance, specifications, or implementation repositories. It preserves observed activity, assigns transparent review signals, maps that activity to a declared DTG capability model, and surfaces cross-workstream implications that deserve attention.

The reading order is intentionally decision-first:

1. **DTG Domain Brief** — what currently requires review, what should be watched, and what the observed portfolio movement means.
2. **Dashboard** — where capability movement, convergence, and alignment signals are concentrated.
3. **Portfolio Status** — the detailed event register and source evidence.

## Decision semantics

A **review-required assertion** is a deterministic coordination or specification/implementation alignment signal. It is not an automatic declaration of failure. A **finding** is a review obligation backed by source evidence and a stable fingerprint. Findings can be explicitly disposed as resolved, superseded, duplicate, accepted risk, or not applicable only through an authorized review decision.

Raw GitHub activity remains evidence; it does not automatically become a governance conclusion.

## Current scope

- Trust over IP DTG coordination and specification repositories;
- OpenVTC implementation and credential repositories;
- transitional lifecycle repositories retained where they remain evidentially relevant;
- commits, pull requests, issues, releases, and repository metadata;
- consolidated change units rather than duplicate PR/merge review obligations;
- deterministic materiality, urgency, capability, convergence, and alignment analysis;
- machine-addressable portfolio assertions with evidence links;
- versioned observation provenance and bounded evidence retention;
- daily and weekly report products.
