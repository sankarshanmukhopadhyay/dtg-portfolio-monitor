# DTG Portfolio Monitor

This site publishes evidence-backed change reports across the Decentralized Trust Graph ecosystem.

## Operating proposition

The monitor does not replace GitHub, task-force governance, specifications, or implementation repositories. It provides a portfolio view over them by preserving observed activity, assigning transparent review signals, and surfacing possible cross-workstream implications.

## Current scope

- 10 Trust over IP DTG repositories
- 3 OpenVTC repositories
- commits, pull requests, issues, releases, and repository metadata
- daily and weekly report products
