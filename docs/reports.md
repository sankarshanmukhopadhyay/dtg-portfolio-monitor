# Reports

The monitor generates daily and weekly reports from the latest collected event set. The current portfolio status is the primary review surface.

[Open the current portfolio status]({{ "/portfolio-status/" | relative_url }}){: .btn .btn-primary }

## Report products

- **Daily digest:** an operational inventory of newly observed activity.
- **Weekly report:** a portfolio-oriented review of material developments, findings, repository health, and cross-workstream implications.
- **Machine-readable evidence:** JSON events and findings under `data/` for audit and downstream analysis.
