# Support

Use GitHub Issues for reproducible collection, routing, retained-state, assurance-status, report or documentation defects and bounded feature proposals. Include the affected revision/evidence window, expected and observed behaviour, and the smallest useful evidence reference.

Security vulnerabilities must follow [`SECURITY.md`](SECURITY.md).

This repository owns the DTG portfolio monitoring and derived status surfaces. DTG source repositories and assurance engines retain authority over their normative content and assessment outcomes.
